# Telegram Sales Bot 🛒

Асинхронный Telegram-бот для онлайн-продаж на базе **Python 3**, **aiogram 3** и **FSM**.

## Функционал:
- 📋 Каталог товаров с Inline-кнопками
- 🛒 Интерактивная корзина (изменение количества, пересчет суммы на лету)
- 📝 Пошаговое оформление заказа (FSM)
- 🚨 Мгновенные уведомления о новых заказах администратору

## Стек технологий:
- Python 3.12+
- aiogram 3.x
- python-dotenv
